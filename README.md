🚀 Тренажёр маркетолога "Твой первый клиент"

Этот репозиторий содержит одностраничный лендинг для симулятора-тренажёра "Твой первый клиент".

Проект реализован с использованием React, Tailwind CSS и Babel в одном файле index.html для максимального упрощения и быстрого развертывания.

Запуск проекта

Клонируйте репозиторий:

git clone [https://www.nic.ru/info/blog/repository/](https://www.nic.ru/info/blog/repository/)


Откройте файл:
Просто откройте файл index.html в любом современном браузере.

Развертывание на GitHub Pages:
Благодаря тому, что весь код находится в одном файле index.html, вы можете легко опубликовать его с помощью GitHub Pages в настройках вашего репозитория.

Стек: React, Tailwind CSS.
